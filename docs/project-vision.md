# Project Vision

## Problem

Schools need a simple way for teachers and students to stay aligned on class materials, assignments, reminders, and grades without relying on scattered tools.

## Users

- Teachers who need to post course content, manage class updates, and review student work.
- Students who need a single place to see classes, upcoming work, and grades.

## Product Goal

Fabric aims to provide a Canvas-style classroom experience with a smaller feature set and a simpler interface. The project focuses on the core classroom loop:

- create a course
- enroll students
- share materials
- publish assignments and announcements
- submit work
- review grades

## MVP Scope

- Authentication
- Student and teacher roles
- Course/class management
- Materials
- Assignments
- Text submissions
- Announcements and reminders
- Grades
- Dashboard and calendar views

## Non-Goals for the MVP

- Direct messaging
- Admin workflows
- Rich notification tracking
- Complex file management
- Parent accounts
