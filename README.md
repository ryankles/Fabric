# Fabric

Fabric is a lightweight learning management app for classrooms. It helps teachers publish materials, assignments, and announcements, while helping students track classes, due dates, and grades in one place.

## Workspace

- `packages/react-frontend`: React + Vite frontend
- `packages/express-backend`: Express + MongoDB backend

## Quick Start

1. Install dependencies from the repo root with `npm install`.
1. Start the backend in `packages/express-backend` with `npm run dev`.
1. Start the frontend in `packages/react-frontend` with `npm run dev`.
1. Open the frontend at `http://localhost:5173`.
